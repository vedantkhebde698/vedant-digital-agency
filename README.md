# 🌐 My Agency Website

A modern and responsive digital agency website built to showcase web development services and collect customer inquiries through a contact form.

## 🚀 Features

* 🎨 Modern and responsive user interface
* 💻 Website development service showcase
* 📩 Contact form for customer inquiries
* ⚙️ Node.js and Express.js backend
* 📊 Inquiry dashboard
* 🔗 Frontend and backend integration
* 📱 Mobile-friendly design

## 🛠️ Technologies Used

**Frontend**

* HTML
* CSS
* JavaScript

**Backend**

* Node.js
* Express.js
* CORS
* dotenv

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/my-agency-website.git
```

### 2. Open the Project

```bash
cd my-agency-website
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the `backend` folder and add the environment variables required by your application.

Never upload passwords, API keys, or other secrets to GitHub.

### 5. Start the Backend

```bash
npm start
```

Your backend should start on the port configured in your server code.

## 🧪 Local Development

Run the backend and frontend according to your local project configuration.

The local website and backend are intended for development and testing.

## 🌍 Deployment

The frontend can be deployed using a static hosting service. The backend requires a hosting service that supports Node.js.

Update the frontend API URL to point to the deployed backend before publishing the website.

## 🔒 Security

* Keep `.env` files private.
* Do not upload `node_modules`.
* Never expose API keys or passwords.
* Validate contact form submissions on the server.
* Use HTTPS for the deployed website.
